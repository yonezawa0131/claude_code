# 過去のプランニング知識の取り込み手順

過去に作成したプランニング資産（媒体の使い分け基準、単価感、選定ルール、過去案件のプラン/実績など）を
このリポジトリの「知識」として取り込むための手順。

## 知識の反映先は2ヶ所のみ

| 反映先 | 入れるもの |
|---|---|
| `config/benchmarks.yaml` | 数値・ルールとして表現できるもの: 媒体別のCPM/VTR/完全視聴率の実勢値、目的別適合スコア、ターゲット親和性、最適化設定の使い分け、運用ノート |
| `.claude/agents/media-planner.md` | 文章でしか表現できない判断基準: 業種×媒体の相性、予算帯別のセオリー、過去の失敗パターン、レビュー観点 |

エンジン（adops/）にはロジックをハードコードしない。知識は必ず上記2ファイルに寄せる。

## 手順

1. 取り込みたいファイルを `knowledge/inbox/` に置く（形式不問: md / yaml / csv / xlsx のエクスポート等）
2. Claude に「inbox の知識を取り込んで」と依頼する
3. Claude は内容を精査し、以下を **差分の提案として** 提示する（勝手に確定しない）:
   - benchmarks.yaml の変更案（現行値 → 提案値、根拠つき）
   - media-planner.md への追記案
4. 人間が承認したら反映し、`knowledge/inbox/` のファイルは `knowledge/archive/YYYY-MM/` へ移動
5. 反映後は `python3 -m pytest -q` と、既存サンプル案件での `adops plan` 再実行で回帰確認

## 注意

- ベンチマーク値の更新は必ず人間の承認を経る（CLAUDE.md の設計前提）
- 出典（どの案件・どの時期の実績か）を benchmarks.yaml のコメントに残す
- 守秘性の高い広告主名は knowledge/ に入れる前にマスクを検討する
