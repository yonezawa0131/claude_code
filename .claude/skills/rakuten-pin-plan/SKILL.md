# rakuten-pin-plan(STEP4: 流入設計)

公開済みの比較記事に対して、検索とは別系統の流入を作るための Pinterest 投稿案を生成する。**位置づけと前提は `notes/playbook/rakuten-affiliate.md` を参照**。**ルーチン作業なので安価なモデルで回してよい。**

## 前提

- 対象は**公開済み**の記事に限る。URL が確定していないと説明文もピンも作り直しになる。
- ピンから記事へ送る導線であり、**ピンに直接アフィリエイトリンクを貼らない**(商品紹介目的以外の掲載・改変の禁止に触れうるため、記事を経由させる)。
- ピンの文言も広告表示の対象になりうる。記事側の PR 表記があることを前提に、ピン単体で断定的な効果を謳わない。

## 手順

1. **対象記事の特定**: `notes/rakuten/ledger.md` の記事表から、状態が「公開済み」でピン未作成のものを選ぶ。
2. **投稿案の生成**: 下のプロンプトを実行する。
3. **表現チェック**: 生成された文言に、煽り・保証表現・効能の断定が無いかを確認する。ピンのタイトルは煽ると保存されずに通報されるだけなので、**選ぶ手助けになる書き方**に寄せる。
4. **画像の作成と投稿**: Canva 等で画像を作り、投稿する(ここは手作業)。
5. **台帳へ記録**: `notes/rakuten/ledger.md` の記事表のピン作成状態を更新する。変更は diff で提示し、push はユーザー明示指示まで保留する。

## プロンプト(投稿案の生成)

```
次の記事をもとに、Pinterestの投稿案を10本作ってください。

記事タイトル：[タイトル]
記事URL：[URL]
想定読者：[ターゲット]

各案について、次を出してください。

・ピンのタイトル(全角20文字以内、検索されそうな言葉を入れる)
・説明文(200文字以内、キーワードを自然に含める)
・画像に載せる文字(2行以内)
・おすすめの配色と構図
・保存されやすいボードの想定

表形式で出力してください。
煽り表現は使わず、選ぶ手助けになる書き方にしてください。
効果や効能を断定する表現、「絶対」「必ず」などの保証表現は使わないでください。
10本が同じ切り口にならないよう、検索意図(比較したい/失敗したくない/使い方を知りたい など)を散らしてください。
```

## チェックリスト

- [ ] 対象は公開済みで URL が確定した記事である
- [ ] 10 本の切り口が散っている(同じ言い換えの繰り返しになっていない)
- [ ] 煽り・保証表現・効能の断定が無い
- [ ] ピンに直接アフィリエイトリンクを貼っていない(記事を経由させている)
- [ ] `notes/rakuten/ledger.md` のピン作成状態を更新した
- [ ] 変更を diff で提示した(push は保留)
