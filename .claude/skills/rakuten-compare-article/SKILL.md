# rakuten-compare-article(STEP2+3: 記事生成とリンク配置)

比較記事の下書きを生成し、体験の追記枠を空け、リンク配置とコンプライアンス確認まで通す。運用の主ループ。**成果条件・報酬上限・品質線の根拠は `notes/playbook/rakuten-affiliate.md` を参照**(ここでは再掲しない)。**ルーチン作業なので安価なモデルで回してよい** — 上位モデルは STEP1 のジャンル選定と四半期の棚卸しに温存する。

## 設計上の前提(ここを外すと運用が壊れる)

- **体験は生成しない。** レビュー本文の体験部分は Claude が書かず `{{体験: 何について書くか}}` のプレースホルダで空ける。使っていない商品の体験を書けば嘘になり、他者レビューの転載は楽天が明示的に禁止している。**プレースホルダを埋めるのはユーザーだけ。**
- **PR 表記は記事テンプレートに固定で入れる。** 記事ごとの判断にしない。
- **価格は本文に書かない。** 変動して陳腐化する。必要ならレンジか「執筆時点」の断りで扱う。

## 手順

1. **入力の確定**: ジャンル・比較商品(5〜7 点)・想定読者・狙うキーワードを確定する。台帳 `notes/rakuten/ledger.md` の採用ジャンルから取る。商品が未定なら、ユーザーが実際に使っている/買ったことのあるものを軸に選ぶ。
2. **下書き生成**: 下のプロンプトを実行する。
3. **体験枠の充足**: 生成物の `{{体験: ...}}` をユーザーに提示し、埋めてもらう。**ここは省略しない。** 埋まらない商品がある場合は、その商品を比較表に残したまま「使っていないので判断を保留する」と本文で明示するか、商品ごと差し替える。
4. **独自情報の確認**: 「自分にしか書けない情報」が **3 つ以上**あるかを数える(実測値・失敗談・特定の使用場面など)。3 つ未満なら公開しない — 独自の価値がないページの量産は、AI 利用の有無に関係なく検索側のスパムポリシー(スケーラブルなコンテンツの不正使用)の対象になる。
5. **リンク配置**: 楽天アフィリエイトで生成したリンクを次の規則で差し込む。リンクの HTML は編集可と明記された箇所以外を改変しない(改変は規約違反)。
   - 比較表の**全商品**に貼る
   - **冒頭には貼らない**(PR 表記は冒頭、リンクは比較を読ませた後)
   - 記事末尾に**関連する消耗品**を併置する
6. **最終チェック**: 下のチェックリストを通す。特に PR 表記・保証表現・効能断定・価格記述。
7. **台帳へ記録**: `notes/rakuten/ledger.md` の記事表に、タイトル・ジャンル・狙うキーワード・状態(下書き/公開済み)・公開日を追記する。変更は diff で提示し、push はユーザー明示指示まで保留する。

## プロンプト(下書き生成)

```
あなたは実際にその商品を使って記事を書く、経験5年のレビュアーです。

次のジャンルと商品について、比較記事の下書きを書いてください。

ジャンル：[ジャンル]
比較する商品：[商品を5点から7点]
想定読者：[誰が何に困っているか]
狙うキーワード：[メインキーワード]
分量：3,000字前後

構成
0. 冒頭に「本記事はアフィリエイト広告を含みます」の一文を独立した行で置く
1. 読者がいま困っている場面の描写
2. この記事が向いていない人(先に外す)
3. 選ぶときに見るべき基準を3つ
4. 比較表
5. 商品ごとのレビュー(良い点・気になる点・向いている人)
6. 使い方別のおすすめ
7. まとめ

ルール
・体験や使用感の記述は、あなたが書かないこと。該当箇所は
  {{体験: この商品の何について書くか}} というプレースホルダで空けること。
  各商品につき最低1つ置くこと。
・すべての商品を良いと書かないこと。合わない場面を必ず書くこと
・価格を具体的な数字で書かないこと(変動するため)
・「絶対」「必ず」「誰でも」などの保証表現を使わないこと
・効果や効能を断定しないこと
・整いすぎた文章にせず、文の長さに揺らぎを作ること
・他者のレビューや口コミを引き写さないこと

マークダウン形式で全文を出力してください。
最後に、{{体験: ...}} の一覧を箇条書きで再掲してください。
```

## チェックリスト

- [ ] 冒頭に PR 表記(「本記事はアフィリエイト広告を含みます」等)が独立した行である
- [ ] `{{体験: ...}}` が全て埋まっている、または未使用商品として本文で保留を明示した
- [ ] Claude が体験・使用感を創作していない
- [ ] 「自分にしか書けない情報」が 3 つ以上ある
- [ ] 全商品に合わない場面/気になる点が書かれている(全部を良いと書いていない)
- [ ] 価格の具体的な数字が本文に無い
- [ ] 保証表現(絶対・必ず・誰でも)と効能の断定が無い
- [ ] 比較表の全商品にリンクを貼った
- [ ] 冒頭にリンクを置いていない
- [ ] 記事末尾に関連消耗品を併置した
- [ ] リンク HTML を改変していない
- [ ] `notes/rakuten/ledger.md` の記事表に記録した
- [ ] 変更を diff で提示した(push は保留)
