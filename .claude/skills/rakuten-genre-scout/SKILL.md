# rakuten-genre-scout(STEP1: ジャンル選定)

比較記事を書くジャンルの候補を出し、実際に着手する 2〜3 個まで絞る。**なぜこの基準なのかは `notes/playbook/rakuten-affiliate.md` を参照**(ここでは再掲しない)。頻度は低く判断が入るので、上位モデルで回してよい。

台帳は `notes/rakuten/ledger.md`。**着手済み・見送りのジャンルを二度検討しないため、必ず先に読む。**

## 手順

1. **台帳の確認**: `notes/rakuten/ledger.md` のジャンル表を読み、既に着手済み・見送り済みのジャンルを把握する。候補出しの前に必ず行う。
2. **候補の一次抽出**: 下のプロンプトを実行し、15 個の候補を表で出す。
3. **自分フィルタ**: 一次候補に対し、ユーザーへ「この中で実際に買って使っているものはどれか」を確認する。**使っていないジャンルは候補から落とす** — 体験を書けないジャンルは品質線(playbook 参照)を割るため、単価が良く見えても着手しない。ここは推測で埋めず必ずユーザーに聞く。
4. **法規制フィルタ**: 残った候補から、効能の断定を避けて書きにくいもの(健康・美容・医薬部外品に寄るジャンル)を落とすか、書ける切り口に限定する。
5. **絞り込み**: 2〜3 ジャンルに絞る。多く抱えても記事が出ないので、次の 1 か月で書き切れる数にする。
6. **台帳へ記録**: 採用ジャンルを `notes/rakuten/ledger.md` のジャンル表へ追記する。**落とした候補も理由付きで記録する**(同じ候補を次の四半期に再検討しないため)。変更は diff で提示し、push はユーザー明示指示まで保留する。

## プロンプト(一次抽出)

```
あなたは楽天市場に詳しいアフィリエイトリサーチャーです。

次の条件をすべて満たす商品ジャンルを15個リストアップしてください。

1. 消耗品または定期的に買い替えが発生する日用品であること
2. 季節による需要の変動が小さいこと
3. 比較して選びたくなる程度に商品数が多いこと
4. 価格帯が1,500円から8,000円であること
5. 実際に使ってみないと分からない差があること
6. 効能や効果を断定せずに紹介できること(健康・美容・医薬部外品に寄りすぎないこと)

各ジャンルについて、次を出してください。

・ジャンル名
・想定される検索キーワードを3つ
・買い替えの頻度
・比較記事にしたときの切り口
・比較すべき項目を4つ
・体験がないと書けない差は何か(1行)

表形式で出力してください。
単価の高さではなく、買い替え頻度の高さを優先してください。
既に比較記事が飽和していそうなジャンルは避けてください。
```
