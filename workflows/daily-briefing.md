# daily-briefing — 朝のブリーフィング生成

## 目的

朝一番の「受信箱スクロールとカレンダー確認」を先回りして 1 枚にまとめ、1 日を判断から始められるようにする。

## 手順

1. Google Calendar MCP で当日のイベントを取得する（終日イベント含む）。
2. Gmail MCP で未読・直近 24 時間のスレッドを検索し、**返信や判断が必要なもの**を抽出する。ニュースレター・通知類は「その他」に件数だけまとめる。
3. `workflows/briefings/YYYY-MM-DD.md` に書き出す:

   ```markdown
   # ブリーフィング YYYY-MM-DD（曜日）
   ## 今日の予定
   - HH:MM–HH:MM <イベント名>（参加者/場所があれば）
   ## 要対応メール
   - <件名> — <差出人>: <要旨と、求められているアクション 1 行>
   ## その他
   - 未読ニュースレター n 件、通知 n 件（重要そうなものだけ件名列挙）
   ```

4. 判断コメント（「これは断ってよさそう」等）は付けてよいが、推測と事実を書き分ける。

## 補足

- MCP コネクタが利用できないセッションでは、その旨を報告して中止する（空のブリーフィングを生成しない）。
- メールの本文引用は要旨に留める（ブリーフィングは commit されるため、機微な全文を残さない）。
