## 途中で見つけた、自分の検定の欠陥

### 1. 前後半の比較が、別の週を測っていた

最初の実装は、パネルを切ってから測り直していた。

```
全期間  -0.742 %/期（133期）
前半    -0.012 %/期（66期）
後半    +0.898 %/期（66期）
```

66期と66期の平均が +0.443% なのに全期間が −0.742%。**部分集合として成立しない。**

944日を472日で切ると、後半の検定は479日目から始まる。479 を7で割った余りは3。
**全期間とは3日ずれた週を測っていた。**

合成データで検算したところ、同じ区切りなら差は 0.081pt で整合していた。
計算ではなく、比較の設計の誤りだった。

→ `split_halves()` で、パネルを切らず**同じ検定の結果を分けるだけ**にした。合計は必ず一致する。

### 2. 頑健性を見ていなかった

暗号資産の週次リターンは大きく裾を引く。**1期の暴落だけで全期間の平均の
符号が変わる**ことがあり、そのとき平均と t 値は実質的に1個の観測を報告している。

→ `robustness()` を追加。実データでは:

```
平均 −0.742% / 中央値 −0.673% / 最大の1期を除くと −1.041%
```

中央値が平均とほぼ同じで、最大の1期を除くとより負に振れる。
**この負の値は外れ値では説明できない。**

### 3. t 検定が、このデータには不適切だった

2つの検定が食い違った。

| 検定 | 結果 |
|---|---|
| t 検定 | t = −1.07（有意でない） |
| 無作為割当 | 観測値は乱数分布の**下位4.7%** |

原因は分かる。観測された期間ごとの標準偏差は **8.00%**、
無作為割当の分布の標準偏差は **0.402%**。2倍近く違う。

t 検定は各期が独立同分布だと仮定するが、実際には市場全体の動きが全期に
共通で乗っている。無作為割当ではその共通部分が上位・下位の両方に入って
**相殺される**。だから無作為割当のほうが精密な検定になる。

**これは無作為割当を作った理由そのもの**だった。それでも判定基準の第一に
t 検定を置いていた。

→ **判定は記録どおり不合格のままにする。** 結果を見てから基準を緩めるのは
当てはめになる。ただし次の検定では、この知見にもとづいて主判定を変える。

## 仮説7の事前登録：銘柄横断の反転

### この仮説がどこから来たか

**上の結果を見てから思いついた。** だからそれを見つけたデータでは検証できない。
`run_preregistered_reversal.py` は 2024-01-01 以降を含むデータを渡されたら
**実行を拒否する**。

### 検定器の陽性対照を先に作った

反転の対照を作ろうとして、最初に間違えた。
**テーマの符号を負にしても反転にはならない。**
テーマは対称なゆらぎなので、符号を変えても「持続する固有の動き」のままで、
順位づけはやはりモメンタムを拾う。

| 合成データ | 上位 − 下位 |
|---|---|
| 反転なし | −0.535 %/期 |
| テーマの符号を反転 | **+10.203 %/期**（モメンタムのまま） |
| **本当の反転を埋め込む** | **−8.472 %/期** |

反転を作るには、**前の期間のリターンそのものを次の期間から引く**必要があった。
`make_synthetic_panel.py --reversal` を追加した。

### 判定基準

| | 基準 |
|---|---|
| A | 上位 − 下位 が**負**であること |
| **B** | **無作為割当の対照で、観測値が乱数分布の下位5%に入ること（主判定）** |
| C | 前半と後半で符号が一致すること |
| D | 最大の1期を除いても符号が変わらないこと |

**B を主判定にしたのは、上の欠陥3から得た知見による。**

そしてこれは正しかった。反転なしの対照では A・C・D がすべて偶然通り、
**B だけが弾いた**。

```
反転あり → 4つすべて合格
反転なし → A ○ / B × / C ○ / D ○ → 不合格
```

### 通っても、日本では取れない可能性が高い

反転を取るには上位群を**空売り**する必要がある。

| | 週あたり |
|---|---|
| レバレッジ手数料（1日0.04%） | 0.28% |
| テイカー手数料（回転率0.79） | 0.38% |
| **合計** | **0.66%** |
| 観測された粗利 | 0.742% |
| **残る** | **0.08%** |

**この検定に通ることは、儲かることを意味しない。**
意味するのは「順位づけに情報がある」ことだけになる。

現物ロングのみ（下位群を買う）なら空売り費用は要らないが、市場ベータを丸ごと負う。
仮説6の期間では、市場自体が年 −16.8% だった。

### 検証を試みた結果：**判定不能**

2021-01-01 〜 2023-12-31 を取得した。**12銘柄しか存在しなかった。**

| 期間 | 取得できた銘柄 |
|---|---|
| 2024-01 〜 2026-08 | **42** |
| 2021-01 〜 2023-12 | **12** |

必要な最低数は15。**日本のアルトコイン市場は、この検定に必要なだけ古くない。**

これは「効果がない」ではなく「**確かめられない**」。区別は重要で、
前者は結論だが、後者は制約になる。

### 検証できる窓は1つだけ残っている：**未来**

仮説を見つけたデータは 2024-01-01 〜 2026-08-01。
**それより後のデータは、私がまだ見ていない。**

これは最も強い形の標本外検証になる。過去のどこを切り出しても、
「切り出し方を選んだ」という疑いが残るが、まだ存在しないデータには残らない。

`run_preregistered_reversal.py` は、次のどちらかを受け付ける。

- 2024-01-01 より**前**で終わるデータ → 銘柄数が足りず判定不能（上記）
- 2026-08-01 より**後**に始まるデータ → **前向き検証**

30期（約7か月）たまれば判定できる。2027年3月ごろになる。

```bash
python trading/scripts/fetch_universe.py \
    --start 2026-08-02 --end <その日> --out-dir trading/data/universe_fwd
python trading/scripts/run_preregistered_reversal.py --dir trading/data/universe_fwd
```

### 検証できないことは、それ自体が結論になる

**確かめられない仮説は、資金を入れる根拠にならない。**

「効果があるかもしれない」と「効果があると確かめた」の差は、
資金を入れてよいかどうかを分ける。前者で入れるなら、それは検証ではなく賭けになる。

この仮説は、少なくとも2027年3月までは前者のままになる。
