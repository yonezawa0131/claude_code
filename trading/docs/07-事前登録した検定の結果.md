# 事前登録した検定の結果

**日中モメンタムは、取引可能な水準では存在しなかった。**

`docs/06` で事前登録した条件のまま、BTC/JPY 1時間足 22,656本
（2024-01-01 〜 2026-08-01、欠損0・重複0・異常行0）で実行した。

## 判定

| | 基準 | 結果 | |
|---|---|---|---|
| 1 | 先読みがない | **合格** | なし |
| 2 | 買い持ちを上回る | **不合格** | −67.65% vs 買い持ち +64.43% |
| 3 | 偶然の水準を超える | **不合格** | シャープ −6.49 / 閾値 1.06 |
| 4 | タイミングに意味がある | **不合格** | ずらした200回のうち、実測より悪かったのは15%だけ |
| 5 | 期間を分けても通用する | **不合格** | 買い持ちに勝った期間 1/6 |

6分割したウォークフォワードは、**6期間すべてマイナス**（−6.58% 〜 −25.96%）。
成績のばらつきも小さい（標準偏差6.15pt）。たまたま悪い期間があったのではなく、
一貫して負けている。

```
取引回数       : 468 回
勝率           : 22.2 %
プロフィットファクタ: 0.23
支払コスト合計 : 154,472 円（元本の51%、総利益の249.9%）
```

## なぜ負けたのか

3つの可能性がある。切り分けた。

| | 総リターン | 勝率 |
|---|---|---|
| コストあり・損切りあり | −67.65% | 22.2% |
| コストあり・損切りなし | −64.51% | 22.4% |
| **コストゼロ・損切りなし** | **−17.59%** | **45.1%** |

**コストを全部外してもマイナス。** 損切りの設定でもない。
シグナルそのものに予測力がない。

### 生の関係を直接測る

セッション冒頭バーのリターンから、終盤バーのリターンを予測できるか。
バックテストを介さず、944セッションの回帰で直接測った。

```
相関          : +0.0289
回帰係数 beta : +0.0236  （標準誤差 0.0265、t = +0.89）
```

**t = 0.89。** 論文が主張する向き（beta > 0）ではあるが、
ゼロと区別がつかない。

条件付き平均で見ると、より直接的になる。

| | 回数 | 終盤バーの平均リターン |
|---|---|---|
| 冒頭が上げたセッション | 469 | **−3.76 bp** |
| 冒頭が下げたセッション | 475 | **−2.63 bp** |
| 差 | | **−1.13 bp** |

**差は −1.13 bp。** 符号すら論文と逆で、大きさは無視できる。
成行の往復コストは 18 bp。**16倍足りない、ではなく、そもそも存在しない。**

## 見つからなかったのか、見る力がなかったのか

ここが一番重要になる。**「検出できなかった」は「存在しない」ではない。**
このデータに、効果があれば見つけられるだけの力があったかを測った。

```
推定値      : -1.13 bp
標準誤差    :  2.78 bp
95%信頼区間 : -6.58 〜 +4.33 bp
```

| 仮に真の効果がこれだけあったら | 検出できた確率 |
|---|---|
| 18 bp（成行で必要な水準） | **100.0 %** |
| 10 bp | 94.9 % |
| 5 bp | 43.5 % |
| 2 bp（指値で必要な水準） | 10.7 % |

**成行で取引可能な水準（18 bp）の効果は、完全に否定できる。**
それだけの効果があれば確実に見つかっていた。
信頼区間の上端（+4.33 bp）でさえ、必要な水準の4分の1にも届かない。

**指値で必要な水準（2 bp）は否定できない。** 検出力が10.7%しかない。
ただしこれは実務的には意味を持たない。`docs/02` で測ったとおり、
**1セッション1回きりの戦略では、指値は成行より悪くなる**。
機会の29.7%が約定せず、しかも取り逃す機会のほうが平均2倍良いからである。

つまり 2 bp の効果が仮にあったとしても、**それを取れる執行方法がこの戦略にはない。**

## この結果が言っていること／言っていないこと

**言っている**
- 2024-01 〜 2026-08 の BTC/JPY 1時間足・UTC 0時区切りにおいて、
  日中モメンタムは**成行で取引可能な水準では存在しない**
- それは検出力不足ではない。18 bp の効果なら確実に見つかっていた
- 負けた原因はコストでも損切り設定でもなく、**シグナルに予測力がないこと**

**言っていない**
- Shen, Urquhart & Wang (2022) が間違っている、ということ。
  **論文の標本期間は今より前**であり、公表された異常収益が
  その後縮小するのは広く観測されている現象になる。
  この基盤にウォークフォワードの減衰検定を入れたのは、まさにそのためだった
- 他のセッション区切り（東京時間、米国時間など）でも同じ、ということ。
  試していない。試すなら試行数を数え直すこと
- 別の取引所・別の期間でも同じ、ということ

## 試したい気持ちについて

区切りを変えれば、48通りのどれかは当たる。
そして48通り試したときに優位性ゼロでも到達する年率シャープは、
この基盤で実測して **2.61**（`docs/05`）。当たったものがそれを超えなければ意味がない。

さらに今回は、**当てはめ以前に信号そのものがない**ことが分かっている。
t = 0.89、符号は期間ごとに入れ替わり、条件付き平均の差は −1.13 bp。
区切りを動かして出てくるものがあるとすれば、それは信号ではなく探索の産物になる。

## 到達点

実データに対して、以下を測り終えた。

| データ | 戦略 | 結果 |
|---|---|---|
| 日足 944本 | EMAクロス・RSI逆張り・ドンチャン・一目均衡表 | 全滅（買い持ちに −68 〜 −122 pt） |
| 日足 944本 | ランダム（対照群） | 見かけ上勝ったが、2つの検定が否定 |
| 1時間足 22,656本 | 日中モメンタム（事前登録） | 5基準中4つ不合格 |

**5つの戦略に、コスト控除後の優位性はなかった。**
そのうち1つは査読論文の裏付けがあるものだった。

これは資金を入れる前に得られた答えである。
