# 実データの結果と、次の検定の事前登録

## 測ったもの

BTC/JPY 日足 944本（2024-01-01 〜 2026-08-01、bitbank から取得）。
欠損バー0、異常行0。元本30万円・GMOコイン取引所の実料率・成行。

この期間、ビットコインは **+58.63%** 上昇し、途中で **−49.42%** の下落を経験した。

**コイン投げが、実装した4戦略すべてに勝った。**

そして4戦略は、58%上げた相場で全部負けている。

これは合成データのレンジ相場で見えていた形（EMAクロス −94%、ドンチャン −55%）が
そのまま実データで再現したもので、**優位性のない相場では動くほど負ける**という
コストの話に一致する。

### 対照群の勝ちは実力か

2つの検定にかけた。どちらも不合格。

**試行数を考慮した判定**

```
観測したシャープ            : 0.74（年率）
優位性ゼロでも到達しうる水準: 0.81
→ この成績は、たくさん試したことだけで説明がつきます
```

**ローテーション検定**（同じ売買パターンをでたらめな時点に200回置き直す）

```
実際のリターン : +60.69 %
ずらした場合   : 中央値 +16.64 %（-39.2 〜 +148.6 %）
→ 上位 26.0 %
```

**4回に1回はこれ以上出る。** ずらした場合の分布が −39% 〜 +149% と極端に広い。
11回の取引・長い保有期間・高いボラティリティでは、この程度のブレは当たり前になる。

つまり **+60.69% は、上げ相場に居合わせた結果**であって、タイミングの実力ではない。

### 買い持ち戦略の検算

`BuyAndHold` の成績（+58.34%）は、理論上の買い持ち（+58.63%）を 0.29pt 下回った。
支払コストは698円＝元本の0.23%で、往復1回ぶんに一致する。
**エンジンのコスト計上が算術と合っていることの確認**にもなっている。

## この結果が言っていること／言っていないこと

**言っている**
- ここで試した4つの古典的な指標戦略に、日足・この期間・このコストでは優位性がない
- その差は小さくない。買い持ちに68〜122ポイント負けている
- 「勝った」ように見えた対照群も、2つの独立した検定で否定された

**言っていない**
- ビットコインの短期売買全般に優位性がない、ということ。
  **試したのは4戦略・1つの足種・1つの期間だけ**
- パラメータを変えれば勝てない、ということ。
  ただし変えて探すなら試行数を数え直す必要がある
- 日中モメンタム（査読論文の裏付けがあるもの）についての結論。
  **日足では検定できない。1時間足が要る**

# 事前登録：1時間足での日中モメンタム検定

**この節は、1時間足のデータを取得する前に書いた。**

## なぜ事前に書くのか

日足で4戦略が全滅したあと、次に1時間足で日中モメンタムを試す。
そこで外れたら、「セッションの区切りを9時（東京）にしてみよう」
「測る本数を2本にしてみよう」と考えるのは自然な反応になる。

区切り4通り × 測る本数2 × 持つ本数2 × 閾値3 = **48通り**。
そして 48通り試したときに優位性ゼロでも到達する年率シャープは、
この基盤で実測して **2.61** だった（`docs/05`）。

**当たったものが 2.61 を超えていなければ、それは試した数の産物でしかない。**

だからデータを見る前に条件を固定する。
`scripts/run_preregistered.py` には戦略もパラメータも渡せない。
結果を見てから条件を変える余地を、構造的になくしてある。

## 仮説

Shen, Urquhart & Wang (2022, *Financial Review*) が報告した、
ビットコインの日中モメンタム。**セッション冒頭の値動きが終盤の値動きを予測する。**
もとは Gao, Han, Li & Zhou (2018) が S&P500 ETF で見つけた現象。

## 固定した条件

| | 値 |
|---|---|
| セッション | 24時間・UTC 0時区切り |
| 測る本数 | 1本（セッション冒頭） |
| 持つ本数 | 1本（セッション終盤） |
| 閾値 | なし（0.0） |
| 損切り | ATR × 2.0 |
| ショート | 使わない（現物を想定） |
| 執行 | 成行・GMOコイン取引所の実料率 |
| 元本 | 30万円・全額 |

**区切りを24時間・0時にしたのは、論文が扱った「1日1セッション」に最も素直だから。**
ビットコインは24時間動くので寄り付きも引けもなく、論文自体は出来高を
セッションの代理変数に使っている。時計で区切るのは近似であり、
**その近似の仕方を結果で選ばないための事前登録**でもある。

## 判定基準（5つすべてを満たしたときだけ「優位性あり」）

1. **先読みがない** — `check_causality` を通ること
2. **買い持ちを上回る** — コスト控除後で
3. **偶然の水準を超える** — 年率シャープが試行数13を考慮した閾値を上回ること
4. **タイミングに意味がある** — ローテーション検定で上位5%に入ること
5. **期間を分けても通用する** — 6分割で過半の期間が買い持ちを上回り、減衰していないこと

5については、各期間の取引が30回に満たない場合は **判定不能** とする。
不合格ではない。**足りないことを、否定と取り違えない。**

## 試行数を13とする理由

この検定だけを見れば事前登録の1件だが、
**同じ実データを何度も見た事実は消えない**ので厳しい側で数える。

- 日足での比較: 6件
- 1時間足での比較（予定）: 7件

合わせて13。

## 外れたときにすること

条件を変えて試すこと自体は構わない。**ただしそれは新しい検定**なので、
試行数を数え直して `run_backtest.py` で明示的に実行する。
`run_preregistered.py` は変えない。事前登録の記録として残す。

そして、**見つからないと分かることも、資金を入れる前に得られる答えである。**
