# 証拠にもとづく運用ルール

精神論を除き、**実証研究で裏付けが取れたものだけ**を並べる。
各項目に、根拠となる研究と、この基盤でどう実装されているかを書いた。

---

## 1. 取引回数を減らす（最も再現性の高い改善策）

**Barber & Odean (2000)**、米国66,465世帯・1991〜1996年。
取引回転率で5分位に分けた結果：

| | 年率ネットリターン |
|---|---|
| 最も活発な上位20% | 11.4% |
| 最も取引しない下位20% | 18.5% |
| 市場平均 | 17.9% |

**決定的なのは、5分位間でグロス（コスト控除前）リターンにほぼ差がなかったこと。**
年率7ポイントの差は、銘柄選択能力の差ではなく、**ほぼ全額が取引コスト**だった。

合成データでの検証も同じ形になった。取引回数とコスト影響の相関は +0.486 で、
251回以上取引した戦略は資金の52.5%をコストで失っていた。

→ 実装：`metrics.evaluate()` が取引回数30回未満で警告を出し、
コストが最終損益を上回った場合も警告する。

## 2. 成行を減らし、指値を使う

**Barber, Lee, Liu & Odean (2009, *Review of Financial Studies*)**、台湾の全取引データ。
個人投資家の集計損失は年率3.8ポイント（台湾GDPの2.2%に相当）だったが、
**この損失はほぼ全て「攻撃的注文」（即時執行を求める成行的な注文）に起因**し、
**受動的な指値注文は短期でむしろ利益**だった。

GMOコインの実料率で計算すると、この差は決定的になる。

| | 往復コスト | 1日5往復・月100往復のコスト |
|---|---|---|
| 成行（Taker 0.05%） | 0.180% | 資金の18.0% |
| 指値（Maker −0.01%） | 0.020% | 資金の2.0% |

元本30万円で1日500円を手取りで狙う場合、必要な粗利は
**成行なら月21.3%、指値なら月5.3%**。同じ戦略でも4倍違う。

**ただし逆選択（adverse selection）に注意。**
指値が約定するのは「価格が自分に向かってきたとき」＝不利な側であることが多い。
市場マイクロストラクチャー研究では、板に残る指値注文は情報を持つ相手と
選択的に約定しやすいという構造が指摘されている。

→ **指値はコストを下げる手段であって、リベート自体を収益源にはできない。**
−0.01%のリベートはスプレッドの数分の1でしかなく、逆選択のコストを相殺できるとは限らない。

→ 実装：`BacktestConfig(order_type=OrderType.MAKER)` で切り替えられるが、
既定は保守側の TAKER。指値の約定確率はモデル化していないので、
MAKER の結果は上振れしている前提で読むこと。

## 3. ポジションサイズを、ケリー最適値の半分以下に抑える

ケリー基準の数理では、賭け金を最適値の c 倍にすると長期成長率は概ね **c(2−c) 倍**になる。

| 賭け金 | 長期成長率 |
|---|---|
| ハーフケリー（c=0.5） | 最大の約75% |
| フルケリー（c=1.0） | 最大 |
| ダブルケリー（c=2.0） | **ゼロ** |

**賭けすぎは、賭け不足より非対称に悪い。** フルケリーで運用すると、
長い取引期間のどこかで約50%規模のドローダウンを経験しうる（Thorp 2008）。

→ 実装：`BacktestConfig(risk_per_trade=0.01)` で、
**1トレードで許容する損失を資金の何%かで指定**できる。
損切りまでの距離からポジションサイズを逆算するため、
ボラティリティが高いときは自動的に小さく建つ。
`metrics.kelly_fraction()` が履歴からケリー値を推定し、半分に落とした値を提示する。

なお「1トレード1〜2%」という実務上の慣行は広く使われているが、
**これはケリー基準のように数学的に最適と証明されたものではなく、経験則**である。
この比率自体を裏付ける査読研究は見つからなかった。

## 4. ドローダウンの上限を、感覚ではなく数値で先に決める

回復に必要なリターン = 1 / (1 − DD) − 1

| ドローダウン | 回復に必要なリターン |
|---|---|
| −20% | +25% |
| −30% | +42.9% |
| −50% | **+100%** |
| −70% | +233% |
| −90% | +900% |

非対称性は深くなるほど加速する。合成データの検証で、
EMAクロス戦略はレンジ相場で −94% を記録した。ここから戻すには +1,567% が要る。

→ 実装：`metrics.recovery_return()`、`money_management_report()`。

## 5. 損切りは「機械的に置くこと」より「損失を利益より長く持たないこと」

機械的なストップロスの一律の優劣は、学術的に**未確定**である。
閾値が狭すぎるストップは超過リターンを悪化させるという報告もある。

一方で **Locke & Mann (2005, *Journal of Financial Economics*)** は、
シカゴ・マーカンタイル取引所のプロ先物トレーダーを分析し、
**全員に処分効果（損失を長く持つ傾向）が存在するが、その度合いが相対的に小さいトレーダーほど
その後の成績が良い**という予測力を確認した。

→ 「損切りを置けば勝てる」ではなく、
「損失ポジションを利益ポジションより著しく長く放置しない」が、証拠のある形。

→ 実装：トレーリングストップは**有利な方向にしか動かない**（`test_trailing_stop_only_moves_favourably`）。
損切りをずらす操作を構造的に禁じている。

## 6. 勝率ではなく、勝率と損益比の組み合わせで判断する

損益分岐に必要な勝率 = 1 / (1 + 損益比)

| 損益比 | 必要勝率 |
|---|---|
| 1:1 | 50.0% |
| 2:1 | 33.3% |
| 2.33:1 | 30.0% |
| 3:1 | 25.0% |
| 1:2 | 66.7% |

**勝率30%でも、平均利益が平均損失の2.33倍あれば期待値はプラス。**
逆に勝率70%でも損益比が1:3なら負ける。「勝率の高い戦略が良い戦略」ではない。

**Odean (1998)** が示した処分効果（利益実現割合14.8% vs 損失実現割合9.8%
＝利益を約50%高い確率で先に確定させる）は、
利益を小さく切り損失を大きく育てる方向に働き、損益比を構造的に悪化させる。

→ 実装：`metrics.breakeven_win_rate()`、`required_reward_risk()`。

## 7. 自動化には、特定のバイアスを消す実証的な裏付けがある

**Liaudinskas (Norges Bank Working Paper 6/2022)** は、
**同一のプロ・デイトレーディング業者内で、人間の裁量取引とアルゴリズム取引を直接比較**した。

- 人間の取引では処分効果が有意かつ大きい
- **アルゴリズムでは処分効果はほぼゼロ（統計的に非有意）**
- さらに、**人間の処分効果は寒い日ほど強まる**が、アルゴリズムは気温と無関係

これは「自動化すれば勝てる」を意味しない。
アルゴリズムには過剰最適化やレジーム変化への脆弱性という別の問題がある。
ただし**処分効果という、金銭的コストが測定されている特定のバイアスについては、
自動化が有効であることが実証されている。**

## 8. 少数だが、実力は持続する

**Barber, Lee, Liu & Odean（台湾、1992〜2006年、約37億トランザクション）**

- デイトレーダーは平均で1日あたり23.9ベーシスポイントの損失（手数料控除後）
- 利益を出すデイトレーダーは平均的な年で全体の **1.6%**
- 手数料控除後に**予測可能・継続的**にプラスの異常リターンを出せるのは **1%未満**
- **ただしその実力は持続する**：上位500人は翌年も1日37.9bps稼ぎ、下位500人は −28.9bps
- 継続率：80%が2年以内に撤退、3年後まで13%、5年後は7%

**勝者に共通する測定可能な特徴として研究が挙げているのは、
「小さく始め、成功してからサイズを拡大する」こと。**

**ブラジル（Chague, De-Losso, Giovannetti）**、19,646人を追跡：
300日以上継続した1,551人のうち、**97%が損失**。
最低賃金を超えたのは1.1%。そして**経験による学習の証拠はなかった**。

## 9. 自己申告の成功報告を基準にしない

判断の基準にするなら、規制当局が全口座に義務付けた開示データを見る。

| 出所 | 損失を出した口座の割合 |
|---|---|
| 米NFA（小売FX、四半期開示） | 約65〜68%（＝黒字は31〜35%） |
| 英FCA（2016年レビュー、CFD） | 約80% |
| 仏AMF（約15,000口座・4年） | 89% |
| ESMA（EU、法域による） | 74〜89% |

SNSやブログの「勝っている人」は、自己選択された母集団の、さらに自己申告である。

## 10. 方向を当てない収益源は、日本の個人にはほぼ閉じている

「ファンディングレート裁定なら方向を当てなくていい」という話には、国内では前提が成立しない。

**国内取引所の「レバレッジ手数料」は、ファンディングレートではない。**
GMOコイン・bitbank はいずれも**買い・売り両方の建玉に一律 1日0.04%（年率約14.6%）を課金**する。
需給で正負が入れ替わる仕組みではないので、**ショートしても受け取れない**。

例外は **SBI VCトレード**で、2024年1月に「レバレッジ手数料率」から
「ファンディングレート」へ変更し、国内で唯一、受け取りも発生する双方向の仕組みを導入した。
ただし個人のレバレッジ上限は2倍のままで、資金効率は海外の10〜100倍とは比較にならない。

**そして「デルタニュートラルならノーリスク」は事実に反する。**
BISワーキングペーパー(No.1087)の分析では、**10倍レバレッジでもサンプル期間の
半分以上の月で先物側が清算**されていた。
この戦略を数十億ドル規模で運用する Ethena 自身が、
「ファンディングリスク」を主要リスクとして明記し、専用の準備金を設けている。

さらに、ビットコインETF導入後にキャリー（現物と先物の価格差）は縮小しており、
全取引所平均で約3ポイント、CMEでは追加5ポイント低下した（平均キャリーの36%、97%に相当）。

海外取引所への道も狭まっている。**Bybitは2025年10月に日本からの新規登録を停止し、
2026年3月23日に既存の日本居住ユーザーも出金専用モードへ移行**した。

税制も不利で、**暗号資産の証拠金取引による利益は分離課税（20.315%）から明確に除外**され、
総合課税（最大約55%）のままである。

## まとめ：この基盤で守っていること

| ルール | 実装 |
|---|---|
| 取引回数を減らす | 30回未満で警告、コスト超過で警告 |
| 成行より指値 | `order_type` で切替。既定は保守側の TAKER |
| ポジションを抑える | `risk_per_trade` で損切り距離から逆算 |
| ケリーの半分以下 | `kelly_fraction()` が半減値を提示 |
| 損切りをずらさない | トレーリングは有利方向のみ（テスト済み） |
| 勝率だけで判断しない | `breakeven_win_rate()` |
| 買い持ちを超えなければ採用しない | 全レポートに併記 |
| 小さく始める | `risk_per_trade` の既定を小さく置く |
