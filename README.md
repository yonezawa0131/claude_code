## trading/ — ビットコイン売買の検証基盤

**儲かる戦略は入っていない。入っているのは、儲かるかどうかを正直に測る仕組み。**

7つの仮説を検定して、**6つが否定され、1つは検定する手段がなかった。**
合格記録のある戦略は存在しないので、`run_live.py --live` は関門で止まる。

引き継ぐなら [`trading/docs/11-引き継ぎ.md`](trading/docs/11-引き継ぎ.md) を最初に読むこと。
現在地・確定していること・**触ってはいけない安全装置**がまとまっている。

```bash
python3 -m venv .venv-trading
.venv-trading/bin/pip install pandas numpy pytest
.venv-trading/bin/python -m pytest trading/tests -q     # 239件
```

ドキュメントは `trading/docs/01`〜`11` に時系列で並んでいる。
**通読する必要はない。** `11`（引き継ぎ）と `08`（目標達成の理論）で足りる。

## 引き継ぐ人へ

この2つのプロジェクトに共通する方針が1つある。

**「見つからなかった」を「見つけた」に書き換えないこと。**

`trading/` は7回探して7回とも空振りした記録であり、`site/` は
「素直な選択肢はすべて塞がっていた」という調査結果から始まっている。
どちらも、都合の悪い結果をそのまま残してある。

そこを曖昧にすると、この基盤は**資金を入れてよい根拠を出す道具**ではなく、
**入れたい理由を作る道具**に変わる。
