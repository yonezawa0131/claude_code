# 戦略：なぜこのジャンルなのか

## 選んだもの

**6畳ワンルーム・賃貸など、狭い部屋での在宅ワークデスク環境。**

サイト名は「6畳デスク研究所」。狭く名乗ることが戦略そのもので、間口を広げると勝てなくなる。

---

## 調査から出てきた矛盾

3方向の調査を突き合わせると、素直な選択肢が全部つぶれる。

**個人が上位表示を取れるジャンルは、単価が低い。**
実SERP観察で個人の占有率が高かったのは、キャンプ場レビュー（86%）、ボードゲーム（80%）、自作キーボード（50%）。どれも物販中心で、1件あたり数十〜数百円。月10万円には45万PVが必要になり、副業で1年以内に到達できる規模ではない。

**単価が高いジャンルは、個人が上位表示を取れない。**
必要PVが最も少ないのは通信（6.8万PV）だが、SERPを見ると「動画配信サービス 比較」で個人12%、「プログラミングスクール 比較」で個人0%。高単価案件の比較キーワードは企業が固めている。

**そして「趣味なら個人が強い」は事実ではなかった。**
キャンプギア、家庭菜園、DIY工具、ペット用品、育児用品 — 直感的に個人向きに見えるジャンルは、すべて「おすすめ」キーワードで個人0%だった。マイベスト・LDK・EC企業・メーカー公式に完全制圧されている。

分かれ目はジャンルではなく**キーワードの型**だった。同じ資格ジャンルでも「スクール比較」は0%、「独学 勉強法 ブログ」は43%。**一次体験がなければ書けないキーワードにだけ、個人の余地が残っている。**

## 交点を狙う

必要な条件は3つ。

1. 一次体験がないと書けない（個人の余地が残る）
2. 高額商品につながる（低単価物販の45万PV問題を回避する）
3. 法規制のリスクが小さい（YMYL・薬機法を踏まない）

デスク環境はこの3つを満たす。SERP観察でも「モニターアーム おすすめ 在宅ワーク」で個人33%、「メカニカルキーボード おすすめ レビュー」で個人33%と、大手が取り切れていない。しかも扱う商品は昇降デスク3〜15万円、チェア10万円超、モニター2〜9万円と単価が高い。

ただし「デスク環境」だけでは、すでにブロガーが多い。**制約を足す**ことで差別化する。

「6畳・賃貸・壁に穴を開けられない・同居人がいる」— この前提は、大手比較メディアのフォーマット（全部を網羅して点数を付ける）に構造的に乗らない。彼らは「6畳の人向け」という限定を置けない。そして日本の賃貸ワンルームの標準は6畳で、読者の母数は十分にある。

## 収益モデル（数字は幅で見る）

**先に結論：物販だけでは月10万円に届かない。高単価案件との混成が必須。**

### 確認できたこと

- **Amazonの「1商品あたり紹介料上限1,000円」は2024年8月7日に撤廃された。** PC Watch・日本ネット経済新聞・ネットショップ担当者フォーラムで一致。高額商品の上限が消えたのは追い風
- ただし**料率自体が低い**。家電＆カメラ 2.0%、ホーム＆キッチン 3.0%（家具カテゴリ単独の料率は一次資料で未確認）
- **Amazonの成果条件は「クリックから24時間以内にカート投入」**。カート投入後は90日有効

### この制約が意味すること

上限撤廃の恩恵は、期待したほど大きくない。5万円の昇降デスクで3%なら1,500円。2.5万円のモニターで2%なら500円。**「高額商品だから1件で数千円」にはならない。**

さらに深刻なのが24時間のCookie。デスクやチェアは数日〜数週間悩んでから買う商品で、「記事を読んだその日にカートへ入れる」という行動を取らせないと成果が消える。**検討期間の長さと24時間という制約が正面から衝突している。**

対策は2つ。記事内で「迷っているならカートに入れておく」導線を明示すること（Amazonはカート投入用のリンク形式を提供している）。そして楽天を併用すること — 楽天のCookieは30日という記述と24時間に短縮されたという記述の両方があり**現行仕様は未確認**だが、30日であれば高額家具では楽天が有利になる。登録後に管理画面で確認して、有利なほうを主軸にする。

### 現実的な構成

| 収益源 | 月間成約 | 1件あたり | 月額 |
|---|---:|---:|---:|
| Amazon（デスク・チェア） | 30〜35件 | 1,500〜2,000円 | 約55,000円 |
| Amazon（モニター・アーム） | 約15件 | 500〜700円 | 約9,000円 |
| 楽天（料率アップショップ中心） | 10〜15件 | 1,000〜1,500円 | 約15,000円 |
| 光回線 または レンタルサーバー | 1〜2件 | 15,000〜20,000円 | 約20,000円 |
| **合計** | | | **約10万円** |

必要な流入は**月1.5〜2万セッション**。低単価物販の45万PVと比べれば桁が違うが、それでも新規ドメインで到達するには時間がかかる。

**この試算の要点は最後の行にある。** 高単価案件をわずか1〜2件混ぜるだけで、必要な物販成約数が大きく減る。在宅ワーク環境という文脈は、光回線・レンタルサーバーに自然につながる数少ないジャンルのひとつで、これがデスク環境を選ぶ実質的な理由になっている。

### 数字の不確かさについて

以下は一次資料で確認できていない。ASPに登録すると管理画面で確認できるので、**登録後に必ず自分で確かめること。**

- Amazonの「家具」「パソコン・周辺機器」カテゴリの正確な料率
- 楽天の家具・家電カテゴリの標準料率
- 楽天のCookie有効期間の現行値（30日か24時間か、情報が矛盾している）
- もしも経由のAmazon料率が直接契約と同じか約90%か（情報が矛盾している）
- 家具の返品・キャンセル率

上の試算はホーム＆キッチン3%・家電2%を家具とモニターに当てはめた推定を含む。**料率が想定より1%低いだけで収益は3割変わる。** 最初の1件が発生した時点で実額を確認し、このドキュメントを更新する。

## 時間軸

新規ドメインは評価が安定するまで3〜6ヶ月、長いと1年かかる（複数のSEO会社の記述が一致）。

| 時期 | やること | 目安 |
|---|---|---|
| 1〜3ヶ月目 | 寸法・計算で書ける記事を10〜15本。ASP登録（もしも・A8） | 流入はほぼゼロ。ここで折れる人が多い |
| 4〜6ヶ月目 | 実際に製品を買って実機記事。ロングテールが拾われ始める | 月1,000〜3,000PV |
| 7〜12ヶ月目 | 順位が付いた記事を強化。高単価案件を接続 | 月5,000〜15,000PV、初成果 |
| 12ヶ月目以降 | 月1.5〜2万セッションを目指す | 月10万円のライン |

**1年計画である。** 3ヶ月で結果を求める設計にはなっていない。

## AI検索への対応

AI Overviewsは全クエリの43〜48%に表示され、表示クエリのCTRは非表示クエリ比で約37%低い水準が新しい基準線になった。購買検討型クエリでも約47%にAIOが出る（日本語2,609キーワードの実測）ので、「比較記事だから安全」は通用しない。

このサイトの防御は**寸法と実測**にある。「6畳に何が置けるか」という問いにAIが答えようとしても、畳の実寸・製品の脚部寸法・壁からのクリアランスを突き合わせた計算は、出典がなければ生成できない。その計算をこちらが持っていれば、AIは引用元としてこちらを選ぶか、読者が「詳しい計算を見たい」でクリックする。

実装としては、記事の冒頭に結論、見出し直下に要点、比較は表、末尾にFAQ、そしてJSON-LD。これらは構築済み。robots.txtでは回答時に参照するAIクローラー（OAI-SearchBot / PerplexityBot / ChatGPT-User）を明示的に許可している — ブロックすると引用機会だけを失い、学習は止まらない（GPTBotをブロックしたサイトの88.2%が依然としてChatGPTに引用された、という調査がある）。

## このサイトが失敗するとしたら

正直に書いておく。

- **1年続かない。** これが最大のリスク。3ヶ月で成果が出ないのは設計通りだが、その期間に書き続けられるかは別の問題
- **料率が想定より低い。** 家具カテゴリの料率が未確認。2%だった場合、必要成約数が1.5倍になる
- **24時間Cookieを突破できない。** 高額家具の検討期間と噛み合わない。楽天併用で回避できるかは、実際に走らせないと分からない
- **実機を買う資金。** 第2層の記事には実際の購入が要る。昇降デスクとチェアで15万円程度の先行投資になる
- **デスク環境ブロガーは多い。** 「6畳・賃貸」の制約で差別化しているが、同じことを考える人はいる。速度と網羅性で先行する必要がある
