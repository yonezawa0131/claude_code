# ASPの選定と設定

## 結論を先に

**物販の主軸はAmazonアソシエイト（直接契約）。楽天とYahooはもしもアフィリエイト経由で、取りこぼし防止のサブに置く。**

「物販なら楽天」という感覚は一般的だが、**このサイトが扱う価格帯では成立しない。** 理由は料率ではなく、楽天に残っている成果報酬の上限にある。

---

## なぜ楽天が主軸にならないのか

### 楽天には「1商品1,000円」の上限が残っている

| | Amazon（直接） | 楽天 | Yahoo（バリューコマース） |
|---|---|---|---|
| 家具の料率 | 3% | 3%（インテリア・寝具・収納） | 約1.02%（目安） |
| PC周辺・家電 | 2% | 2% | 同上 |
| **1件あたりの上限** | **なし**（2024年8月7日に撤廃） | **1商品1,000円**（標準料率の商品） | 確認できず |
| 同一ユーザーの月間上限 | — | 3,000円 | 確認できず |
| Cookie | クリックから24時間以内にカート投入 | 同じく24時間以内にカート投入 | 30日 |
| 成果の猶予 | カート投入後180日以内の発送・支払い | カート投入後89日以内 | — |
| 報酬の受け取り | 銀行振込 | **楽天キャッシュ**が既定 | 銀行振込 |

このサイトが扱うのは、電動昇降デスク3〜15万円、ワークチェア10万円前後、モニター2〜9万円という価格帯。

**楽天では、15万円のチェアを売っても入るのは1,000円。** 3,000円の小物を売った場合と変わらない。単価の高い商品を扱うという、このジャンルを選んだ理由そのものが消える。

Amazonは2024年8月7日に上限を撤廃しているので、5万円のデスクなら3%で1,500円、15万円のチェアなら4,500円がそのまま入る。

料率アップショップに登録された商品は楽天の1,000円上限の対象外になるが、家具ジャンルにどれだけ存在するかは確認できていない。**もし高料率の家具ショップを見つけたら、そこは優先的にリンクする価値がある。**

### 報酬が現金で受け取りにくい

楽天の報酬は既定で**楽天キャッシュ**に入る。銀行振込に切り替えるには、**3ヶ月連続で月3,001円以上の確定報酬**を得たうえで申請が必要になる。

副収入として現金がほしい場合、軌道に乗るまでは実質ポイント収入になる。Amazonともしもは銀行振込が既定なので、この点でも差がある。

### Cookieは24時間（30日ではない）

「楽天のCookieは30日だからAmazonより有利」という記述をよく見かけるが、**これは2019年3月以前の旧仕様。** 楽天市場は2019年4月1日から24時間に短縮されている（楽天トラベル・楽天ブックスなど他サービスは30日のまま）。

Amazonと同じ「24時間以内にカート投入」が条件で、そこから購入までの猶予が楽天89日・Amazon180日。**この点でもAmazonのほうが長い。**

### 楽天が有利な点もある

楽天は**商品指定なしで成果になる。** リンクをクリックした読者が、リンク先とは違う商品を買っても成果が付く。

Amazonは2026年4月20日施行の規約改定で、この「ついで買い」（ハロー効果）の報酬を事実上廃止し、同一ASIN・同一カテゴリのバリエーション商品に限定した。**この一点だけは楽天のほうが柔軟になった。**

デスク周りの小物（ケーブル収納、チェアマット、デスクライト）は、楽天のほうが取りこぼしが少ない可能性がある。だから消すのではなく、サブとして併用する。

## 登録の順番

記事が0本の状態で申し込むと落ちる。**第1層の記事を5〜10本公開してから**着手する。

### 1. もしもアフィリエイト（審査なし）

最初に登録する。ここから楽天とYahooの提携を申請できる。

- 最低支払額 1,000円（住信SBIネット銀行なら1円）
- 振込手数料 無料
- 現金・銀行振込が既定
- 支払いサイクル 翌々月末
- W報酬制度（+12%）はAmazon・楽天には**適用されない**。それ以外の広告主のみ

楽天はもしも経由でも直接契約と同率なので、もしもを通しても損はない。むしろ振込条件が良い。

### 2. A8.net（審査なし）

案件数が最も多い。第3層（光回線・レンタルサーバー）で使う。デスク環境の記事が育ってから、在宅ワークの回線として自然に接続する。

### 3. Amazonアソシエイト（直接契約）

**流入が出てから申請する。** 理由は審査条件にある。

- サインアップから**180日以内に3件の適格販売**が必要
- 1注文内の複数商品は1件としてカウントされる
- 自己購入・家族や友人への依頼購入は規約違反でカウントされない
- 180日以内に達成できないとアカウントは閉鎖され、**同じアソシエイトIDでは再開できない**（新規IDでの再申請は可能）

つまり、検索流入がまったくない状態で申請すると、180日を空振りして失敗する。**記事が検索に載り始めてから申請するのが正しい順番。**

それまでの間は、もしも経由のAmazonでつなぐこともできる。ただし**もしも経由のAmazonは2023年2月から直接契約の約90%**になっているので、直接契約が通ったら切り替える。

### 4. バリューコマース（審査あり）

Yahoo!ショッピングと連携できる唯一のASP。もしも経由のYahooが0.77%に対し、バリューコマース直接は約1.02%と高い。ただし管理の手間が増えるので、**成果が出てから判断すればよい。**

## リンクの貼り方

### 設定する場所

`src/consts.ts` の `AFFILIATE` に識別子を入れる。

```ts
export const AFFILIATE = {
  amazonTag: 'yourname-22',   // AmazonのトラッキングID
  rakutenId: '',
  amazonUseCartLink: false,
} as const;
```

**`amazonTag` が空のうちは、ASINで書いたAmazonリンクは出力されない。** タグの付いていないリンクを出しても成果にならず、読者を外に送るだけになるため、意図的にそうしている。

### 記事での書き方

```yaml
products:
  - name: エルゴトロン LX デスクマウント
    links:
      amazon: B00MIBN71I                          # ASIN（英数字10桁）
      rakuten: https://hb.afl.rakuten.co.jp/...   # 発行されたURLをそのまま
      yahoo: https://ck.jp.ap.valuecommerce.com/... # 同上
      official: https://www.ergotron.com/         # 公式。sponsored は付かない
```

- **Amazonは ASIN だけ書けばよい。** `https://www.amazon.co.jp/dp/{ASIN}/ref=nosim?tag={ID}` の形式でリンクが組み立てられる。ASINは商品ページの「登録情報」欄にある英数字10桁
- **楽天とYahooは、ASPが発行したURLをそのまま貼る。** これらは商品URLの形が一定でないため、IDから組み立てる方式にしていない
- 完全なURLを書けば、`amazonTag` が未設定でもそのまま使われる。ASPが発行したリンクをそのまま使いたいときはこちら

`links` を書かないか空にすると、ボタンは「リンク準備中」という表示になる。**提携審査が通る前に記事を公開しても、リンク切れは発生しない。**

### 規約上の注意

**ASPが発行したリンクの `href` とパラメータは絶対に変えないこと。** このサイトの実装は、URLをそのまま使い、`rel="sponsored nofollow noopener"` を**追加するだけ**にしている。rel属性の追加は多くのASPで問題にならないとされる実務上の落としどころで、アクセストレードは「リンクコードの改変にあたらない」と公式に明言している。

ただし注意点がある。**楽天とバリューコマースは「発行されたHTMLコードの改変」を規約で禁じている。** このサイトの実装はURLだけを取り出して自前のボタンにしているため、厳密には改変にあたる可能性がある。

回避する方法は2つ。

1. **もしもアフィリエイト経由にする。** もしもの「かんたんリンク」は、Amazon・楽天・Yahooを横並びのボタンとして表示する機能をASP自身が提供している。3社並記の形式そのものが公認されている
2. **記事を `.mdx` にして、発行されたHTMLをそのまま貼る。** MDXは有効にしてあるので、拡張子を `.mdx` に変えれば生のHTMLを書ける

心配なら2番が確実。ただし楽天の「モーションウィジェット」はJavaScriptの読み込みが必要なので、静的サイトでは避けること。静的な `<a><img></a>` 形式の「商品リンク」を使う。

### カートに入れるリンクについて

`AFFILIATE.amazonUseCartLink` を `true` にすると、Amazonのボタンが `gp/aws/cart/add.html` 形式（クリックで直接カートに入る）になる。

Amazonの成果条件は「クリックから24時間以内のカート投入」なので、検討期間の長い高額家具では有効に見える。しかし**この形式は現行のAmazon公式ヘルプに記載が見当たらない。** 昔から使われていて動作報告は多いが、正式にサポートされている保証はない。

既定では無効にしてある。使う場合は、自分のアソシエイトIDで実際に成果が計上されることを確認してから。

## 表示義務

このサイトには2種類の表示義務がある。**どちらも実装済み。**

| 根拠 | 内容 | 場所 |
|---|---|---|
| 景品表示法（ステマ規制） | 「本ページはプロモーションを含みます」 | 全記事のファーストビュー |
| Amazonアソシエイト運営規約 | 「Amazonのアソシエイトとして、6畳デスク研究所は適格販売により収入を得ています。」 | フッター（全ページ） |

**この2つは別の義務。** ステマ規制は法令、Amazonの開示文はAmazonとの契約上の要求で、片方を出せばもう片方が不要になるわけではない。

なお、成果報酬だけを受け取っていて広告主とのやり取りが一切ない場合、ステマ規制上のPR表記は法的には任意になりうるという整理もある（楽天アフィリエイトはそう案内している）。ただし商品の無償提供を受けたりタイアップを行ったりした場合は必須になる。**任意であっても出しておくほうが安全なので、このサイトでは常に出している。**

## 登録後に必ず確認すること

管理画面にログインしないと分からない数字がある。**推定で運用せず、登録したら実額を確認してドキュメントを更新すること。**

- Amazonの「家具」「パソコン・周辺機器」カテゴリの正確な料率
- 楽天の料率アップショップに家具ジャンルがどれだけあるか
- Yahoo!ショッピングの家具・家電の料率
- もしも経由のAmazonが直接契約の何%か（同じ商品でリンクを作って見込み報酬を比較する）
- Amazonの2026年4月改定に「AI生成コンテンツの明記義務」が含まれるか。**記事作成にAIを使うなら、規約本文を自分で確認すること**

料率が想定より1%低いだけで、収益は3割変わる。
