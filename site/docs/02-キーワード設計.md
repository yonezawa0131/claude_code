# キーワード設計

## 原則：狙ってはいけない型

調査で、個人サイトの占有率が0%だったキーワードには共通の形がある。

```
一般名詞 + おすすめ / ランキング / 比較
```

「デスク おすすめ」「モニターアーム 比較」「オフィスチェア ランキング」は、新規ドメインでは取れない。マイベスト・LDK・価格.com・メーカー公式が上位を固めており、彼らと同じ土俵（網羅性・更新頻度・被リンク）では勝負にならない。

**狙うのは、制約が入ったキーワード。**

```
制約（部屋の広さ / 賃貸 / 幅の上限 / 同居人）+ 具体的な行為
```

制約付きのキーワードは、大手比較メディアが構造的に書けない。彼らのフォーマットは「全部を網羅して点数を付ける」であり、「6畳で壁に穴を開けられない人向け」という前提を置いた記事はそのフォーマットに乗らない。

---

## 記事の3層構造

### 第1層：土台（最初の3ヶ月）

寸法・規格・計算で答えが出るもの。実機を持っていなくても、根拠を示して書ける。ここで一次情報性を作る。

| 想定キーワード | 記事の核 | カテゴリ |
|---|---|---|
| 6畳 デスク 大きさ / 6畳 レイアウト 在宅 | 畳の実寸から逆算した、置けるデスク幅の計算 | layout |
| 賃貸 モニターアーム 設置できるか | 天板の厚み・背面クリアランスの閾値 | monitor |
| デスク 奥行き 60cm 足りる | モニターサイズ別の必要奥行き | desk |
| 椅子 引くスペース 何cm | 立ち座りに必要な後方スペース | chair |
| 昇降デスク 狭い部屋 | 脚部の設置面積と昇降時のクリアランス | desk |
| ワンルーム デスク 配置 ベッド | 動線と通路幅から決まる配置パターン | layout |

これらは「答えが数字で出る」ため、AI要約に食われても「詳しい計算を見たい」でクリックが残りやすい。逆に、曖昧なアドバイス記事はAIに完全に代替される。

### 第2層：実機（4ヶ月目以降、実際に買ってから）

自分の部屋で実際に使った記録。ここが収益の主軸になる。

| 想定キーワード | 前提 |
|---|---|
| （製品名） 6畳 レビュー | 実際に設置した |
| （製品名） 賃貸 設置 | 実際に取り付けた |
| （製品名） 奥行き 実測 | 実際に測った |

**買っていない製品でこの層を書かない。** 書いた瞬間にサイトの前提が崩れる。

### 第3層：接続（第1層が回り始めてから）

デスク環境から自然につながる高単価案件へ。

- 在宅勤務の回線（光回線・ホームルーター）
- 作業環境の電気代（電力切替）

読者の文脈から外れた案件を無理に挟むと、直帰率が上がって第1層の評価まで落ちる。第1層の記事が検索から流入を得るようになってから着手する。

## キーワードの探し方

無料でできる範囲：

1. **ラッコキーワード**でサジェストを一括取得（検索ボリュームは有料だが、サジェスト自体は無料）
2. 取得した語を**Googleキーワードプランナー**に投入してボリュームを確認
3. 候補キーワードで**実際に検索して、上位10件のドメインを数える**

3番目が一番重要で、一番飛ばされやすい。**上位に個人サイトが1つもないキーワードは、ボリュームがあっても書かない。** 今回の調査で0%だったキーワード群は、どれも検索ボリュームは十分にあった。ボリュームは参入可能性を意味しない。

## 判断基準

書く前に確認する：

- [ ] 上位10件に個人サイトが2つ以上あるか
- [ ] 自分の部屋で確認できる内容か（確認できないなら第1層として寸法で書けるか）
- [ ] 大手比較メディアのフォーマットに乗らない前提（制約）が入っているか
- [ ] 記事から自然につながる商品があるか
