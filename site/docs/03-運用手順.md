# 運用手順

## 0. 公開前に埋めるもの

`src/consts.ts` の以下は仮の値のままなので、公開前に必ず変更する。

| 項目 | 現在 | やること |
|---|---|---|
| `SITE.url` | `https://rokujo-desk.pages.dev` | 独自ドメインを取ったら書き換える。canonical・OGP・sitemap すべてがこの値を見ている |
| `SITE.author` | `運営者` | 実名またはハンドルネーム。未設定だと運営者情報ページに警告が出る |
| `SITE.email` | 空 | 連絡先。未設定だとお問い合わせページに警告が出る |

`src/pages/about.astro` のプロフィール文も、自分の状況に合わせて書き換える。「なぜこのテーマについて書けるのか」が伝わることが、E-E-A-T の Experience にあたる。

## 1. ドメイン

独自ドメインを取る。`.pages.dev` や無料ブログのサブドメインは、ASPの提携審査で落ちる要因になる。

- 取得先：お名前.com / ムームードメイン / Cloudflare Registrar など
- 年額 1,000〜1,500円程度（`.com`）
- サイト名と対応がつく文字列にする（例：`rokujo-desk.com`）

## 2. デプロイ（Cloudflare Pages）

静的サイトなので無料枠で足りる。

```
ビルドコマンド : npm run build
出力ディレクトリ: dist
ルートディレクトリ: site
Node バージョン : 22
```

1. GitHub にこのリポジトリを push
2. Cloudflare Pages で「Connect to Git」→ リポジトリを選択
3. 上記のビルド設定を入力
4. デプロイ後、Custom domains から独自ドメインを接続

`public/_headers` にキャッシュとセキュリティヘッダーの設定を入れてあるので、Cloudflare Pages がそのまま読む。

## 3. Google Search Console

ドメイン接続後すぐに登録する。**サイトマップの送信を忘れない。**

- プロパティ：ドメインプロパティ（DNS認証）を推奨
- サイトマップ：`https://（ドメイン）/sitemap-index.xml` を送信
- URL検査で、公開した記事を都度インデックス登録リクエスト

新規ドメインは評価が安定するまで3〜6ヶ月かかる。最初の2ヶ月は順位が付かなくても異常ではない。

## 4. アクセス解析

Google Analytics 4 を入れる場合は、`src/layouts/BaseLayout.astro` の `<head>` にタグを追加する。

追加したら、プライバシーポリシー（`src/pages/privacy-policy.astro`）の「2-2. アクセス解析ツールによる情報の取得」に、使用しているツール名を明記する。現在は「アクセス解析ツール」と一般化した書き方にしてあるので、GA4 を入れたら Google Analytics と名指しで書く。

AI検索からの流入（ChatGPT / Perplexity / Claude）は referrer で判別できる。参照元レポートで `chatgpt.com` `perplexity.ai` を確認できるようにしておく。

## 5. ASP登録

### 順番

記事が0本の状態で高単価ASPに申し込むと落ちる。**第1層の記事を5〜10本公開してから**申し込む。

1. **もしもアフィリエイト**（審査なし）
   - Amazon・楽天の提携がここから申請できる
   - W報酬制度で通常報酬に上乗せがある
   - 振込手数料が無料、最低支払額1,000円
2. **A8.net**（審査なし）
   - 案件数が最も多い。第3層（回線・電力）で使う
3. **Amazonアソシエイト**
   - 審査あり。申請後180日以内に一定数の適格販売が必要という独自条件があるので、**流入が出てから申請する**
   - もしも経由でも Amazon の紹介は可能なので、直接契約が通らない間はもしもを使う
4. **バリューコマース**（審査あり）
   - Yahoo!ショッピングと連携できる唯一のASP

### 提携が通るまで

`AffiliateLink` コンポーネントは、URL が空のとき「リンク準備中」という表示に切り替わる。提携前でも記事は公開でき、リンク切れも起きない。frontmatter の `url` を後から埋めればよい。

## 6. 記事を追加する

```bash
cd site
npm run dev              # http://localhost:4321
```

1. `src/content/posts/（英数字のファイル名）.md` を作る
2. `docs/04-記事テンプレート.md` の frontmatter をコピーして埋める
3. `npm run audit:content` でチェック
4. `npm run build` が通ることを確認
5. commit → push → Cloudflare Pages が自動デプロイ
6. Search Console でインデックス登録をリクエスト

`draft: true` にしておくと本番ビルドから除外される。書きかけを push しても公開されない。

## 7. 公開後にやること

- **記事は書き直す。** 順位が付かない記事は、キーワードを変えるか、内容を足す。`updatedDate` を入れると更新日が表示される
- **Search Console の検索クエリを見る。** 自分が想定していないキーワードで表示されていることがある。そのキーワードで記事を書き直すか、新しく書く
- **リンク切れを定期的に確認する。** 製品は廃番になる。価格の記述も古くなる
