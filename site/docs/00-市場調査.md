# 市場調査の結果

2026年8月時点。3方向（ASP・報酬単価 / SEO競合性 / AI検索環境と法規制）から調査した。

数字の一部は調査会社や個人ブログの二次情報にもとづくもので、精度にばらつきがある。判断の前提として重い数字には、その旨を書いた。

## 1. SEO：個人サイトはどこで生きているか

実際に検索し、上位表示されたドメインを「大手メディア・企業」「個人」に分類して数えた。24キーワードを観察。

### 「おすすめ・ランキング」型は個人の生存率ゼロ

| 検索キーワード | 個人サイトの占有率 | 上位を占めているもの |
|---|---|---|
| クレジットカード おすすめ 比較 | 0% | ダイヤモンド系・カブタン・みんかぶ・価格.com・カード会社公式 |
| 育毛剤 おすすめ ランキング | 0% | マイベスト・クリニック公式 |
| 犬 おもちゃ おすすめ 噛む | 0% | マイナビ・マイベスト・専門通販 |
| 猫 トイレ おすすめ ランキング | 0% | LDK・マイベスト・ユニチャーム公式 |
| 抱っこ紐 おすすめ 新生児 | 0% | VERY・たまひよ・LDK・エルゴベビー |
| 家庭菜園 初心者 野菜 おすすめ | 0% | マイナビ農業・ハイポネックス・サカタのタネ |
| DIY 電動工具 おすすめ | 0% | DIY FACTORY・Jackery・楽天 |
| キャンプ ギア おすすめ | 0% | Honda・BE-PAL・ビックカメラ |
| ロードバイク 初心者 おすすめ | 0% | ダイワサイクル・マイベスト・sakidori |
| プログラミングスクール 比較 | 0% | リセマム・HonNe・スクール公式 |
| ふるさと納税 おすすめ 返礼品 | 0% | ふるなび・ふるさとチョイス |

**「趣味ジャンルなら個人が強い」という通説は、実際のSERPでは成立していない。** キャンプも家庭菜園もDIYもペットも、「おすすめ」の語がつくキーワードは比較メディア大手（マイベスト、LDK）・EC企業・メーカー公式に完全制圧されている。

### 一次体験型は個人が生きている

| 検索キーワード | 個人サイトの占有率 |
|---|---|
| キャンプ場 レビュー 行ってみた ブログ | 86% |
| ボードゲーム おすすめ 初心者 | 80% |
| 自作キーボード おすすめ キット | 50% |
| 簿記2級 独学 勉強法 ブログ | 43% |
| コーヒー豆 通販 おすすめ | 40% |
| 釣り ルアー おすすめ バス釣り | 40% |
| 吉祥寺 カフェ おすすめ | 35% |
| モニターアーム おすすめ 在宅ワーク | 33% |
| メカニカルキーボード おすすめ レビュー | 33% |
| ワイヤレスイヤホン おすすめ 比較 | 14% |
| 動画配信サービス 比較 おすすめ | 12% |

分かれ目は**ジャンルではなくキーワードの型**だった。同じ「資格・学習」でも、「スクール比較」は個人0%、「独学 勉強法 ブログ」は43%。同じガジェットでも、大型カテゴリ（ワイヤレスイヤホン14%）より狭い製品（モニターアーム33%）のほうが個人が入れる。

参考になる実例として、`note.com/mocchan`（デスク環境をテーマにした個人）が「メカニカルキーボード」と「ワイヤレスイヤホン」という別々の激戦キーワードの両方で上位に出ていた。テーマを絞って積み上げると複数キーワードに波及することを示している。

### 新規ドメインの立ち上がり

評価が安定するまで3〜6ヶ月、長いと1年（複数のSEO会社の記述が一致）。**最初の半年はロングテールで評価を稼ぐ期間**と割り切るのが現実的。

## 2. AI検索：情報系サイトの流入は構造的に減った

### AI Overviews の表示率とCTR

- 表示率：全クエリの43〜48%（Semrush 48% / Similarweb 43%、2026年前半）
- CTR：AIO表示クエリで1.76%（2024年半ば）→ 0.61%（2025年9月）→ 1.3%（2025年12月・底）→ 2.4%（2026年2月）
- AIO非表示クエリのCTRは約3.8%。**表示/非表示のギャップ約37%が新しい基準線**になった

調査会社によって下落幅の数字が2〜4倍違う（Seer -61%、Pew -46.7%、Amsive -15.5%）。単一の数字を信じず、レンジで捉える。

### 「比較検討クエリなら安全」は崩れている

日本語2,609キーワードの実測（2026年4月）で、**購買検討型クエリでもAIO出現率は約47%**。トランザクショナルなら無風、という前提はもう使えない。

### 食われないための条件

AIが持てないもの＝**一次体験・実測データ・写真**。E-E-A-T の Experience が、順位を上げるためというより「AIの引用元として選ばれる」ために効くようになった。

### 引用されやすい書き方（複数ソースで一致）

1. 冒頭に「◯◯とは△△である」という定義・結論を置く
2. 各見出しの直下に結論を1〜2文
3. 比較は表・箇条書きで構造化
4. 具体的な数値を本文に含める
5. 末尾にFAQセクション（Q&A形式が最も抽出されやすい）
6. 著者情報と出典を明示

### AIクローラーの扱い

GPTBot は**学習専用**で、ブロックしても ChatGPT の検索機能（OAI-SearchBot / ChatGPT-User）には影響しない。GPTBot をブロックしているサイトの **88.2% が依然として ChatGPT の回答に引用された**という調査がある。

→ 回答時に参照する系（OAI-SearchBot / PerplexityBot / ChatGPT-User）は必ず許可する。ブロックすると引用機会だけを失う。

### llms.txt

Anthropic・Perplexity・You.com などが対応、**Google は未対応を明言していない**。効果の評価は割れており、2026年時点で必須施策ではないというのが複数ソースの一致。実装コストがほぼゼロなので置くが、時間はかけない。

## 3. 収益：月10万円に必要なPVの逆算

ジャンル別に「単価 × 承認率 → 必要件数 → CVR → クリック数 → CTR → 必要PV」で試算した。CVR・CTR は業界の一般的な目安にもとづく仮定値で、実測ではない。

| ジャンル | 想定単価 | 承認率 | 必要件数 | 必要PV |
|---|---:|---:|---:|---:|
| 通信（格安SIM・光回線） | 3,500円 | 70% | 41件 | **約6.8万** |
| ウォーターサーバー等 | 3,000円 | 70% | 48件 | 約8.0万 |
| クレカ・証券口座 | 8,000円 | 50% | 25件 | 約8.3万 |
| VPN・SaaS | 2,500円 | 75% | 54件 | 約9.0万 |
| 電力・ガス切替 | 2,500円 | 75% | 54件 | 約9.0万 |
| 美容医療 | 5,000円 | 55% | 37件 | 約12.3万 |
| VOD | 1,000円 | 80% | 125件 | 約15.6万 |
| 転職 | 3,000円 | 60% | 56件 | 約18.7万 |
| 引越し見積もり | 1,000円 | 60% | 167件 | 約20.9万 |
| Amazon/楽天 物販（低単価品） | 200円 | 92% | 544件 | **約45.3万** |

読み取れること：

- 単価が10〜20倍違っても、承認率とCVRの差で必要PVの差は縮む。**高単価＝ラクではない**
- 低単価の物販は45万PV必要。副業で1年以内は現実的でない
- ただしこの物販の行は「1件200円」＝低単価商品の想定。**高額商品なら話が変わる**（→ 戦略ドキュメント参照）

### ASP

- **審査なしで登録できる**：A8.net、もしもアフィリエイト
- **審査あり・比較的通る**：afb、バリューコマース、Amazonアソシエイト
- **審査が厳しい**：Rentracks等のクローズド型、金融・美容医療の個別案件（記事数不足・サイト未完成で落ちる）

## 4. 法規制で個人が踏みやすい地雷

| 規制 | 個人への影響 |
|---|---|
| **ステマ規制**（景表法・2023年10月施行） | 「広告」と分かる表示が必要。**ファーストビュー内**に置く。ページ末尾だけ、リンクの奥だけは「不明瞭な表示」と判断されうる。判断はサイト全体の印象で総合的に行われる |
| **薬機法** | 健康食品・化粧品で医薬品的な効能を謳うと違反。2016年の消費者庁通知で**アフィリエイトサイトも対象と明記**され、「何人も」規定で個人も対象 |
| **健康増進法** | 第32条の2は「何人も」が主語。**「個人の感想です」と書いても効果の断定は規制対象になりうる** |
| **特定商取引法** | 紹介のみのサイトには法的な表記義務なし。自分で商品を売る場合は必須 |
| **個人情報保護法** | 2026年1月に制度改正方針が公表され、Cookie ID等への規制強化・課徴金導入の方向。法案成立見込みは2026年5〜6月、施行はその1〜2年後（**現時点では法案段階**） |

**LINE公式アカウントの注意**：規約上、アカウントを第三者商品の広告媒体として使うことは原則禁止。「LINEでリスト構築」を勧める記事は多いが、規約違反でアカウント停止のリスクがある。リスト構築はメール配信を軸にする。
