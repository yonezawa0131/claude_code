# 6畳デスク研究所

狭い部屋（6畳ワンルーム・賃貸）での在宅ワークデスク環境に特化したアフィリエイトサイト。

## なぜこのジャンルなのか

市場調査の結果、素直な選択肢はすべて塞がっていた。

- 「〇〇 おすすめ」型のキーワードは、ジャンルを問わず企業が90〜100%占有している（実SERP観察24キーワード）
- 個人が勝てるのは一次体験型のキーワードだが、そうしたジャンルは物販中心で単価が低く、月10万円に45万PVが必要になる
- 単価の高いジャンル（通信・金融・スクール）の比較キーワードは、個人の占有率が0〜12%

この3つの制約の交点として、**「一次体験がないと書けない」「高額商品につながる」「YMYLを踏まない」**を満たすジャンルを選んだ。詳細は [docs/01-戦略.md](docs/01-戦略.md)。

## 開発

```bash
npm install
npm run dev              # http://localhost:4321
npm run build            # 型チェック込みのビルド
npm run audit:content    # 法令表記・カテゴリ・評価の整合チェック
npm run assets           # favicon と OGP 画像の再生成
```

## 構成

Astro 7 の静的サイト。JavaScript はビルド後ほぼ残らない。

```
src/
  consts.ts           サイト名・URL・カテゴリ。設定はここに集約
  content.config.ts   記事の frontmatter スキーマ
  content/posts/      記事（Markdown）
  components/         比較表・商品カード・PR表記など
  lib/schema.ts       JSON-LD の組み立て
  pages/              ルーティング
scripts/
  audit-content.mjs   公開前チェック
  generate-assets.mjs favicon / OGP 画像の生成
```

## 設計上の判断

**アフィリエイトリンクは `AffiliateLink` コンポーネント経由でのみ出す。** `rel="sponsored nofollow noopener"` を強制し、URL が未設定なら「リンク準備中」の表示に落ちる。ASP の提携審査が通る前でも記事を公開でき、リンク切れが発生しない。

**PR表記はファーストビューに出す。** ステマ規制（景品表示法・2023年10月施行）では、表示位置が「消費者が気づきにくい場所」だと不明瞭な表示と判断されうる。記事末尾ではなく本文冒頭に固定している。

**`tested: false` の製品に評価を付けられない。** `audit:content` がエラーで止める。使っていない製品に星を付けることは、読者に対しても景品表示法の観点でも問題になる。

**AI クローラーは回答参照系だけ許可している。** OAI-SearchBot / PerplexityBot / ChatGPT-User を許可。学習専用の GPTBot 等をブロックしても引用は止まらない（ブロックしたサイトの88.2%が依然として ChatGPT に引用されたという調査がある）ため、ブロックは引用機会だけを失う。

## 公開前に必要なこと

`src/consts.ts` の `SITE.url` / `SITE.author` / `SITE.email` は仮の値。未設定のまま公開すると、運営者情報とお問い合わせのページに警告が表示される。[docs/03-運用手順.md](docs/03-運用手順.md) のチェックリストを参照。
