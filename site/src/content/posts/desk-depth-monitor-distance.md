奥行き60cmのデスクに27インチモニターを置くと、目が近すぎるのではないか。狭い部屋でデスクを選ぶときによく出てくる不安ですが、**計算してみると、目との距離自体は基準を満たします。** 足りなくなるのは別の場所です。

## 基準になる数字は「40cm以上」

厚生労働省の「情報機器作業における労働衛生管理のためのガイドライン」（2019年改正）は、ディスプレイと目の距離について次のように定めています。

| 項目 | 推奨値 |
|---|---|
| ディスプレイと目の視距離 | おおむね40cm以上（できれば50cm以上） |
| 画面上端の高さ | 目の高さとほぼ同じか、やや下 |
| 見下ろす角度 | 10度以下が目安 |

**この基準はインチ数に依存しません。** 「27インチなら何cm離す」という公的な区分表は存在せず、24インチでも27インチでも40cm以上という一律の基準です。インチ別の目安を示している記事もありますが、それらは各サイト独自の数値で、公的な根拠があるものではありません。

## 奥行き60cmで視距離は足りるか

モニターを一番奥に置いたとき、画面から座っている人の目までがどれだけ離れるかを分解します。

一般的な27インチモニターは、スタンドを付けた状態で**奥行き18〜21cm**です。24インチでは16〜24cm。実際の製品では、Dell S2725H（27インチ）がスタンド装着時に奥行き176.5mm、パネル部だけなら59.04mmです。

スタンドの脚は前後に広がるので、画面そのものは天板の奥から15cm前後の位置に立ちます。

```
天板の奥行き 60cm
－ 画面の位置（奥から約15cm）
＝ 画面から手前の縁まで 約45cm
```

そして座っているとき、目は天板の手前の縁より後ろにあります。上体が縁のあたりにあり、頭はその上にあるので、10〜20cm程度は後方に位置します。

```
画面から縁まで 45cm ＋ 縁から目まで 10〜20cm
＝ 視距離 55〜65cm
```

**40cm以上という基準は満たします。** 「できれば50cm以上」という水準にも届きます。奥行き60cmのデスクで27インチが近すぎる、という心配は、少なくとも数字の上では成立しません。

## 実際に足りなくなるのは手前のスペース

問題は目との距離ではなく、**モニターの手前に何cm残るか**です。

```
天板の奥行き 60cm
－ スタンドの占有 18cm
＝ 手前に残る 42cm
```

この42cmにキーボードとマウス、そして腕を置くことになります。日本語配列のフルサイズキーボードは奥行き15cm前後、テンキーレスでも13cm前後。キーボードを置くと、手前に残るのは25cm前後です。

書類を開いて置くことはできません。ノートを広げるのも厳しい。**「27インチが近すぎる」ではなく「手が窮屈」という形で不満が出ます。**

奥行き70cmのデスクが27インチに推奨されるのは、視距離のためというより、この手前のスペースを確保するためです。

## モニターアームでスタンドの分が空く

ここが狭い部屋での最大の打ち手です。モニターアームに交換すると、スタンドが占めていた16〜24cmがまるごと不要になります。

| 構成 | 手前に残るスペース |
|---|---|
| 奥行き60cm ＋ 純正スタンド | 約42cm |
| 奥行き60cm ＋ モニターアーム | 約55〜58cm |
| 奥行き70cm ＋ 純正スタンド | 約52cm |

**奥行き60cmのデスクにアームを付けると、奥行き70cmのデスクにスタンドを置いた場合より広く使えます。** アームは支柱が天板の奥の縁に立つだけで、その手前は完全に空きます。モニターを天板の後ろ側にせり出させることもできるため、実質的にはさらに稼げます。

10cm奥行きの大きいデスクを買うより、アームを買うほうが安く、部屋も広く保てる、という判断になります。

ただし**アームはどの天板にも付きません。** 天板の厚み、中空構造かどうか、壁との距離という条件があります。特にIKEAの安価な天板に多いハニカム構造（中空）は、クランプの締め付けで内部が潰れることがあります。この判定については[賃貸のモニターアーム設置条件](/posts/rental-monitor-arm)で詳しく扱っています。

## 幅のほうはどうか

奥行きとは別に、幅も確認しておきます。

| モニター | 横幅の目安 |
|---|---|
| 24インチ | 約53〜55cm |
| 27インチ | 約61〜62cm |

幅100cmのデスクに27インチを置くと、残りは約39cm。マウスを動かす範囲としては足りますが、モニターの横に物を置く余裕はありません。

デュアルモニターにする場合、27インチ2枚で約122cm。**幅120cmのデスクには収まりません。** 24インチ2枚なら約108cmで、幅120cmにぎりぎり収まります。狭い部屋でデュアルを組むなら、24インチ2枚か、27インチ1枚＋縦置き24インチという構成が現実的です。

## 部屋全体との関係

ここまでは天板の上の話ですが、デスクの奥行きは部屋全体のレイアウトに直結します。壁からの占有奥行きは「天板の奥行き＋椅子を引く75cm」で決まるため、奥行き60cmと70cmの差10cmが、そのまま通路の余裕を削ります。

団地間6畳の短辺は約255cm。奥行き70cmのデスクを置くと145cmを使い、残りは110cm。奥行き60cmなら135cmで、残り120cm。この10cmが、ベッドを置けるかどうかの分かれ目になることがあります。詳しくは[6畳に置けるデスクの大きさ](/posts/6jo-desk-layout)で計算しています。

**アームを使って奥行き60cmで済ませるという判断は、天板の上だけでなく、部屋全体に効いてきます。**

## まとめ

- 視距離の基準は40cm以上（できれば50cm以上）。インチ数による区分はない
- 奥行き60cmのデスクでも、27インチの視距離は55〜65cm程度で基準を満たす
- 不足するのは手前の作業スペース。スタンドが18cm前後を占める
- モニターアームにすると、奥行き60cmが実質75cm前後として使える
- 27インチの幅は約61cm。デュアルにするなら24インチ2枚が現実的
